# V39 自动求解流水线交付说明

## 新增能力

V39 在 V38 的基础上新增自动求解流水线：

- 自动扫描题面与数据目录；
- 自动识别题型和主指标候选；
- 自动检索本地历史资料；
- 自动生成 baseline 与候选路线；
- 自动生成可执行 Python adapter；
- 自动运行实验并保存指标；
- 自动登记实验注册表；
- 自动终审推荐或打回。

## 与 V38 的区别

V38 解决“已有实验结果是否可信”。V39 解决“能否主动生成并运行第一批实验”。二者关系是：V39 负责探索，V38/V39 gate 负责裁判。

python -m pytest .\tools\tests -q

## 现实评价

V39 已经不是单纯工作流文档，而是有可执行 adapter 生成和实验登记的半自动求解底座。但它的自动生成模型仍是通用第一轮探索，比赛当天要冲高奖，还需要接入更强模型 API、历史论文向量检索、领域 adapter 模板和多轮参数搜索。
