# V36/V38 有资源类别 C 题专向说明

## 覆盖范围

当前自包含包覆盖的 C 题相关历史资源包括：

- `2012A` 葡萄酒评价排序；
- `2012C` 脑卒中环境因素；
- `2013C` 古塔变形；
- `2014C` 生猪经营管理；
- `2023C` 蔬菜销售经营。

## 运行方式

统一通过 V38 入口运行：

```powershell
cd tools
$env:PYTHONIOENCODING='utf-8'
python run.py --self-contained
```

## C 题专向产物

输出位于：

```text
tools/run/v38_self_contained/v35/
tools/run/v38_self_contained/v36/
tools/run/v38_self_contained/v38/
```

最终以 `v38/v38_explicit_role_gate.json` 的审计结论为准。

## 当前能力边界

这套 C 题专向不是模板硬套，而是提供“路线探索和证据裁判”的框架。新 C 题仍需要：

- 根据题目补充真实数据读取逻辑；
- 设计至少一条 baseline；
- 设计若干候选路线；
- 输出主指标、推荐理由和 limitations；
- 通过 V38 gate 后再进入论文写作。
