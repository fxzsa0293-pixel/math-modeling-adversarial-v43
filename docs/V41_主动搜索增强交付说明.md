# V41 主动搜索增强交付说明

## 本版目标

V41 解决“如何主动找到更强路线”的问题。它不是只增加审核，而是增加候选模型族、特征工程、调参和 hybrid 路线。

## 相比 V40 的更新

- 路线池从可信性筛查扩展为主动搜索。
- 预测/表格路线新增 Ridge alpha search、RandomForest search、GradientBoosting search。
- 新增 residual hybrid：趋势模型 + 残差修正。
- 自动构造滞后、滚动均值、平方项、交互项。
- 评价类增加 PCA 排序和稳定性加权排序。
- CLI 增加 `--timeout-seconds`，控制每条 adapter 的最长运行时间。
- 测试从 12 条增加到 13 条，覆盖新增搜索路线。

## 真实评价

V41 的主动搜索能力明显强于 V40，但内置 demo 是混合资料库测试，只能证明搜索流程和模型族扩展有效。真正比赛中仍要把 `data_root` 指向当前赛题数据，并根据题目补专用优化/机理 adapter。
