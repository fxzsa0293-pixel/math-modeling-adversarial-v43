# V36/V38 完整版本整理说明

## 当前交付口径

本包以 V38 为实际运行版本，保留 V36 名称的文件夹只是历史目录名。请以 `SKILL.md`、`README_REPRODUCE.md` 和 `tools/run.py` 为准。

## 主要组件

| 文件 | 作用 |
| --- | --- |
| `tools/run.py` | V38 统一入口，支持 `--self-contained` 和 `--data-root`。 |
| `tools/v38_explicit_role_gate.py` | 显式角色证据门，负责最终审计。 |
| `tools/v30_real_benchmark_adapters.py` | 早期真实 benchmark adapter，已禁用虚假 2012A wrapper。 |

| `tools/tests/test_self_contained_skill.py` | 自包含与负向测试。 |

## 运行命令

```powershell
cd tools
$env:PYTHONIOENCODING='utf-8'
python run.py --self-contained
python -m pytest .\tests -q
```

## 重要解释

V38 中案例数不是 12，而是 11。原因是旧 V30 的 2012A wrapper 存在虚假默认指标风险，已删除出运行流。2012A 仍由 V36 adapter 使用真实数据覆盖。
