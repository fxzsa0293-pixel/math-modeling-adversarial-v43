# V42 模型能力增强交付说明

## 本版目标

V42 继续增强“主动找到更强路线”的能力，同时检查并修复 V41 增强后暴露的 bug。重点是扩展模型族、提升搜索覆盖、增强预测安全性和清理终审文案。

## 相比 V41 的新增能力

- 新增 `elastic_net_feature_search`：稀疏线性模型搜索，帮助筛选有效特征。
- 新增 `extra_trees_feature_search`：极随机树搜索，增强非线性鲁棒探索。
- 新增 `model_family_ensemble`：融合 Ridge、RandomForest、GradientBoosting 三类预测。
- 保留并增强 `residual_hybrid_forecast`：趋势模型 + 残差修正。
- `regression_metrics` 增加非有限预测/目标检查，避免 NaN/inf 指标污染 registry。
- `final_judge.py` 重写为英文稳定文案，清理旧乱码。
- `problem_parser.py` 的 notes 改为稳定机器可读标记，例如 `target_unknown`。

## 真实评价

V42 的模型搜索能力强于 V41：它不只会试 Ridge/RandomForest/GBDT，还加入了 ElasticNet、ExtraTrees 和模型族集成。它仍然是第一轮自动探索器，不是最终论文模型；但现在更有机会主动发现超过 baseline 的候选路线。
