# Data policy

The public repository includes only repository-native demonstration data under `examples/quickstart/`.

`data/reference_root/` is a local-only location for reference materials obtained lawfully by each user. It is excluded from Git. Do not commit competition papers, problem statements, attachments, datasets, drawings, or source code unless their redistribution license has been verified and preserved.

Historical benchmark commands require the corresponding local corpus. The main V44 solver accepts any user-supplied data directory through `--data-root`; the public Quickstart does not require third-party material.
